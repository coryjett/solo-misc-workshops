Each product answers one question

agentregistry

What exists, and is it approved?

  • Catalog of agents, MCP servers, models
  • Owners, data class, dependencies
  • Approvals and access policies
  • Finds what runs unregistered

agentgateway

How does anything reach it safely?

  • One door for MCP tools and LLMs
  • Identity and per-tool scope
  • Guardrails and data masking
  • On-behalf-of tokens, traces

kagent

Where does it run?

  • Kubernetes-native agent runtime
  • Agents and MCP servers as resources
  • Deployed by the registry
  • Tools reached through the gateway
