Agent platform demo environment

Registry, gateway and agent runtime on one Kubernetes cluster. The registry decides what exists and who owns it. The gateway is the one path to tools, agents and models, and it enforces identity and policy on every call.

    Control plane. The registry holds every agent, MCP server and model with its owner and data class. Changes go through approval, and access policies decide what each team sees.

    Data plane. agentgateway carries every tool, agent and model call. Identity, tool access, guardrails and token exchange are enforced per call, not per app.

    Agents. Solo Enterprise for kagent runs agents in gVisor sandboxes on Agent Substrate. Their model and tool calls go through the gateway as the signed-in user, so the same policies apply to people and agents.

    Identity. Keycloak keeps the demo self-contained. Pointing sign-in at your own IdP is configuration, not code.

    Teams, people and data in this demo are fictional. Use the arrow keys to step through a walkthrough.
