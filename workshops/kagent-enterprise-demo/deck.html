Solo Enterprise for kagent

Controls for platform teams

Enterprise

Your identity provider

Sign-in through Entra ID, Okta, Keycloak or any OIDC provider. Groups come from the token.

Enterprise

Access policies by group

Who may build agents, who may only use them, and who may read traces and prompts.

Core

Approval before changes

Chosen tools pause for approval in the UI. The decision is kept with the session.

Enterprise

Tracing and analytics

Model and tool calls per agent and user, with tokens and timing, stored in your cluster.

Core

Sandbox and egress

gVisor or microVM, no outbound access until a policy allows a host. Secrets injected at the proxy.

Enterprise

One console

Fleet dashboard, worker capacity, snapshots, schedules and evaluations, with supported builds.

Core features are in open-source kagent 1.0; Enterprise ships them as supported, digest-pinned builds. Every card is shown live in the demo except the external IdP (the lab uses the bundled provider with three test roles) and evaluations.

Agent Substrate

How Agent Substrate runs agents

Worker pool

A few pods, each a gVisor sandbox

agent 4

agent 11

free

idle: suspend

new message: resume

Snapshot store

Idle agents saved to object storage

Capacity tracks use

Pods run only the agents active right now.

Sandboxed

gVisor by default, with a microVM option.

Checkpoints

Save a session at any turn, resume or fork it.

Two agents are active on workers; the rest are saved in the snapshot store and use no compute. When an agent goes idle it is suspended to storage and its slot is freed. The next message resumes it on any free worker. Do not name specific microVM technologies.

kagent with agentgateway

kagent with agentgateway

kagent can send model and tool calls through agentgateway, so agents follow the same policies as applications.

Identity

The user's token is passed through, so model and tool policies apply per user.

Cost

Token budgets and rate limits by user, team or model.

Safety and audit

Guardrails, data masking and a single log of every call.

Per-user identity uses token passthrough today. A combined user and agent token is in progress.
